# خادم التعاون — السكرتير

يشغّل التسجيل والأصدقاء والتحديات والمشاركات والمزامنة الاجتماعية. لا يستقبل قاعدة الحياة أو الملاحظات كاملة.

## التشغيل

Python 3.12 أو أحدث، دون مكتبات خارجية:

```bash
python3 server/server.py --db secretary-social.sqlite --host 127.0.0.1 --port 8080
```

للتطوير على محاكي Android أدخل `http://10.0.2.2:8080` في شاشة التعاون. للهاتف المتصل بـUSB:

```bash
adb reverse tcp:8080 tcp:8080
```

ثم أدخل `http://127.0.0.1:8080`. في تشغيل بعيد ضع الخادم خلف HTTPS وأدخل العنوان المشفر. التطبيق يقبل HTTP لعناوين التطوير المحلية الثلاثة فقط.

## الوظائف

- حسابات باسم مستخدم، كلمات مرور PBKDF2-SHA256 مع salt مستقل، جلسات opaque لمدة 30 يوماً ورموز مخزنة مجزأة في الخادم.
- طلب صداقة، قبول/رفض من المستلم، إزالة علاقة.
- تحديات عامة أو للأصدقاء أو خاصة بدعوة. المقاييس: التعلم، الالتزام، الأهداف، الاستمرار، المشاريع، التحسن.
- هدف شخصي لكل مشارك وتقدم إضافي موثق بوصف يكتبه المستخدم. الترتيب حسب نسبة الإنجاز حتى 100%؛ القيم مبلغ عنها ذاتياً، وليست قياساً علمياً أو تحققاً آلياً من الأداء.
- صلاحية مستقلة لكل مشاركة: خاص، أصدقاء، عام داخل المنصة، أعضاء مجموعة تحدٍ. سحب المشاركة وإلغاء العضوية يعيدان تطبيق الصلاحيات عند المزامنة التالية.
- طابور عمليات في الهاتف. Idempotency-Key يربط المعاملة بردها داخل transaction واحدة؛ إعادة الطلب نفسه لا تضاعف التقدم. إعادة المعرف بمحتوى مختلف ترفض.
- مزامنة عند التسجيل/فتح التطبيق، بعد إجراء اجتماعي، يدوياً، ومن JobScheduler عند توفر الشبكة. جدولة الخلفية تقريبية ويقرر النظام وقت تشغيلها.
- تشغيل هذا الخادم ليس نشره للعامة؛ بيانات الاختبارات حسابات وهمية محلية فقط.

## التحقق

```bash
python3 -m unittest discover -s server -p 'test_*.py' -v
```

تغطي الاختبارات HTTP حقيقياً على منفذ مؤقت، عزل الحسابات، صلاحيات المشاركات، إلغاء الوصول، التحديات الخاصة، عضوية المجموعة، ترتيب التقدم، وتكرار الطلبات.
