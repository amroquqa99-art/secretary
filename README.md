# السكرتير — main: تطوير 0.8.0 قيد العمل، آخر إصدار متحقق 0.7.0

تطبيق Android عربي بـ Kotlin وJetpack Compose. البيانات الشخصية محلية في SQLite v7، والتعاون اختياري عبر خادم Python المرفق.

## ما يحتويه الإصدار

السكرتير المحلي يقدم أوامر ومراجعة حياة وهرم أهداف وخطة أسبوع وبحث وسجل محادثة، مع تأكيد قبل التغيير وتنفيذ مرة واحدة. أضيف إدخال ونطق عربي/إنجليزي محليان داخل الشاشة عند توفر حزم الهاتف، وتأكيد صوتي مرتبط بالاقتراح. في 0.7.0 استبدل محرك النموذج بمحرك llama.cpp وملف Qwen2.5-0.5B GGUF اختياري وتجريبي لتقليل الذاكرة وحجم التطبيق؛ جودة العربية لم تجتز معيار الاعتماد النهائي. حزم الصوت المستقلة وكلمة التنبيه والعمل الصوتي والجهاز مقفل ما زالت غير مدمجة. المتبقي في [FINAL_RELEASE_ROADMAP.md](FINAL_RELEASE_ROADMAP.md).

- مهام كاملة مع مهام فرعية وتبعيات وتكرار وتعريف إنجاز وأسباب تعثر وتأجيل.
- أهداف SMART وتاريخ تقدم وربط العمر/10 سنوات/السنة/الشهر/الأسبوع/اليوم، مشاريع ومسار حرج ومساحات عمل، تقويم وعادات وسجل تاريخي.
- مراجعات يومية وأسبوعية وتعافٍ ولوحة قيادة محسوبة من بيانات المستخدم.
- ملاحظات Markdown وبحث وروابط داخلية وخلفية.
- جلسات تركيز ووضع صارم لحجب التطبيقات، ومرشح DNS للمواقع.
- حسابات وأصدقاء وتحديات وترتيب ومشاركة بصلاحيات ومزامنة اجتماعية آمنة من التكرار.
- نسخ احتياطية مشفرة مع المرفقات واستعادة ذرية، وحفظ رمز الحساب في Android Keystore.

القائمة الدقيقة وحدود كل ميزة في [STAGE3_ACCEPTANCE.md](STAGE3_ACCEPTANCE.md). تفاصيل الإصدار الحالي في [RELEASE_0_7_0.md](RELEASE_0_7_0.md)، والتوثيق السابق في [VERIFICATION.md](VERIFICATION.md) و[ANDROID_TEST_RESULTS.md](ANDROID_TEST_RESULTS.md). ملفات المتابعة القديمة محفوظة كسجل تاريخي فقط.

## بناء Android

يتطلب JDK 21 وAndroid SDK Platform 37.0 وBuild Tools 36.0.0 وNDK `30.0.16248370` وCMake `3.22.1`. ضع مسار SDK في `local.properties` على جهازك، أو استخدم Android Studio.

```bash
./gradlew clean --no-build-cache :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

ينزل سكربت `gradlew` إصدار Gradle المحدد عند أول تشغيل. يتطلب البناء الأول اتصالاً بمستودعات Google وMaven وGitHub لتنزيل مصدر llama.cpp المثبت ببصمة SHA-256. يمكن إعداد نسخة مصدر محلية بنفس revision ثم تمرير `SECRETARY_LLAMA_CPP_DIR` عند البناء. يعمل التطبيق بدءاً من Android 8 (API 26).

## التعاون

اقرأ [server/README.md](server/README.md) لتشغيل الخادم والاتصال من الهاتف أو المحاكي. الخادم غير منشور على الإنترنت ضمن هذه الحزمة. قاعدة الحياة لا ترفع تلقائياً: المشاركة والمزامنة الاجتماعية صريحتان، ونقل البيانات الشخصية بين الأجهزة عبر النسخة المشفرة.

## الاختبارات المستقلة

```bash
python3 checks/verify_migration.py
python3 checks/verify_v4.py
python3 checks/verify_v5.py
python3 -m unittest discover -s server -p 'test_*.py' -v
```

المرحلة الرابعة مستمرة. بعد 0.7.0 بدأ مسار 0.8.0 باسترجاع محلي محدود مرتبط بالسؤال من المهام والأهداف والملاحظات وسجل المحادثة قبل بناء سياق النموذج. هذا الاسترجاع حتمي/لفظي وليس embeddings، لذلك لا يُوصف بعد بأنه ذاكرة دلالية كاملة. اعتماد نموذج عربي جيد على الهاتف وحزم صوت مستقلة وكلمة التنبيه والذاكرة الدلالية القائمة على embeddings ما زالت متبقية. تحقق CI للـWIP الجديد جارٍ ولم يُضم إلى أرقام 0.7.0 الموثقة.

## نموذج المحادثة التجريبي 0.7.0

النموذج المتاح للتنزيل الاختياري هو Qwen2.5-0.5B-Instruct Q4_K_M بصيغة GGUF، بحجم 469 MiB. محرك CPU المحلي هو llama.cpp/ggml مثبت بمراجعة مصدر وبصمة محددتين. لا يوجد تنفيذ تلقائي ولا اتصال بخادم أثناء الاستدلال. الأوامر المعروفة تبقى بالقواعد المحلية.

اختبارات Linux أظهرت RSS نحو 712 MiB مقابل 2.1 GiB في المسار السابق، لكن جودة العربية ما زالت ضعيفة. النموذج متوقف افتراضياً، ولا يمثل اعتماداً نهائياً للسكرتير العربي. اقرأ [RELEASE_0_7_0.md](RELEASE_0_7_0.md) و[LOCAL_MODELS.md](LOCAL_MODELS.md).

هذه النسخة تستخدم توقيع debug نفسه الخاص بـ0.6.0. قاعدة SQLite ما زالت v7؛ لا تحتاج حذف التطبيق للترقية من 0.6.0. احتفظ بنسخة بيانات مشفرة قبل استبدال APK أقدم ذي توقيع مختلف. مفتاح إنتاج release لم يُنشأ بعد.
