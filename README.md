# السكرتير — الإصدار التجريبي 0.6.0، تطوير المرحلة الرابعة

تطبيق Android عربي بـ Kotlin وJetpack Compose. البيانات الشخصية محلية في SQLite v7، والتعاون اختياري عبر خادم Python المرفق.

## ما يحتويه الإصدار

السكرتير المحلي يقدم أوامر ومراجعة حياة وهرم أهداف وخطة أسبوع وبحث وسجل محادثة، مع تأكيد قبل التغيير وتنفيذ مرة واحدة. أضيف إدخال ونطق عربي/إنجليزي محليان داخل الشاشة عند توفر حزم الهاتف، وتأكيد صوتي مرتبط بالاقتراح. في 0.6.0 أضيف مسار Qwen3 محلي اختياري وتجريبي؛ جودة العربية والذاكرة لم تجتازا معيار الاعتماد النهائي. حزم الصوت المستقلة وكلمة التنبيه والعمل الصوتي والجهاز مقفل ما زالت غير مدمجة. المتبقي في [FINAL_RELEASE_ROADMAP.md](FINAL_RELEASE_ROADMAP.md).

- مهام كاملة مع مهام فرعية وتبعيات وتكرار وتعريف إنجاز وأسباب تعثر وتأجيل.
- أهداف SMART وتاريخ تقدم وربط العمر/10 سنوات/السنة/الشهر/الأسبوع/اليوم، مشاريع ومسار حرج ومساحات عمل، تقويم وعادات وسجل تاريخي.
- مراجعات يومية وأسبوعية وتعافٍ ولوحة قيادة محسوبة من بيانات المستخدم.
- ملاحظات Markdown وبحث وروابط داخلية وخلفية.
- جلسات تركيز ووضع صارم لحجب التطبيقات، ومرشح DNS للمواقع.
- حسابات وأصدقاء وتحديات وترتيب ومشاركة بصلاحيات ومزامنة اجتماعية آمنة من التكرار.
- نسخ احتياطية مشفرة مع المرفقات واستعادة ذرية، وحفظ رمز الحساب في Android Keystore.

القائمة الدقيقة وحدود كل ميزة في [STAGE3_ACCEPTANCE.md](STAGE3_ACCEPTANCE.md). تفاصيل الإصدار الحالي في [RELEASE_0_6_0.md](RELEASE_0_6_0.md)، والتوثيق السابق في [VERIFICATION.md](VERIFICATION.md) و[ANDROID_TEST_RESULTS.md](ANDROID_TEST_RESULTS.md). ملفات المتابعة القديمة محفوظة كسجل تاريخي فقط.

## بناء Android

يتطلب JDK 21 وAndroid SDK Platform 37.0 وBuild Tools 36.0.0. ضع مسار SDK في `local.properties` على جهازك، أو استخدم Android Studio.

```bash
./gradlew clean --no-build-cache :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

ينزل سكربت `gradlew` إصدار Gradle المحدد عند أول تشغيل. يتطلب البناء الأول اتصالاً بمستودعات Google وMaven. يعمل التطبيق بدءاً من Android 8 (API 26).

## التعاون

اقرأ [server/README.md](server/README.md) لتشغيل الخادم والاتصال من الهاتف أو المحاكي. الخادم غير منشور على الإنترنت ضمن هذه الحزمة. قاعدة الحياة لا ترفع تلقائياً: المشاركة والمزامنة الاجتماعية صريحتان، ونقل البيانات الشخصية بين الأجهزة عبر النسخة المشفرة.

## الاختبارات المستقلة

```bash
python3 checks/verify_migration.py
python3 checks/verify_v4.py
python3 checks/verify_v5.py
python3 -m unittest discover -s server -p 'test_*.py' -v
```

المرحلة الرابعة مستمرة؛ تشغيل نموذج عصبي محلي وحزم صوت مستقلة وكلمة التنبيه والذاكرة الدلالية ما زالت متبقية.

## نموذج المحادثة التجريبي 0.6.0

أضيف Qwen3-0.6B INT4 اختيارياً مع LiteRT-LM 0.17.1. ينزل الملف فقط بطلب المستخدم (329 MiB) وتفحص بصمته، أو يستورد ملف محلي. كل إجراء مقترح يحتاج تأكيداً. العربية والذاكرة لم تجتازا معيار اعتماد النموذج النهائي؛ يبقى متوقفاً افتراضياً. اقرأ [RELEASE_0_6_0.md](RELEASE_0_6_0.md) و[LOCAL_MODELS.md](LOCAL_MODELS.md) للحدود والقياس الفعلي. الصوت المستقل والذاكرة الدلالية وكلمة التنبيه لم تنفذ بعد.

المحرك الجديد يحتاج JDK 21 للاختبارات وAPK بمعمارية 64 بت. احفظ نسخة بيانات مشفرة قبل استبدال APK أقدم بتوقيع مختلف.
