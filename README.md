# السكرتير — الإصدار 0.4.0، بداية المرحلة الرابعة

تطبيق Android عربي بـ Kotlin وJetpack Compose. البيانات الشخصية محلية في SQLite v6، والتعاون اختياري عبر خادم Python المرفق.

## ما يحتويه الإصدار

أضيف السكرتير المحلي بقواعد أوامر وخطة يوم وبحث وسجل محادثة، مع تأكيد قبل التغيير وتنفيذ مرة واحدة. النموذج العصبي والصوت ما زالا غير مدمجين. المتبقي للنسخة النهائية في [FINAL_RELEASE_ROADMAP.md](FINAL_RELEASE_ROADMAP.md).

- مهام كاملة مع مهام فرعية وتبعيات وتكرار وتعريف إنجاز وأسباب تعثر وتأجيل.
- أهداف SMART وتاريخ تقدم، مشاريع ومسار حرج ومساحات عمل، تقويم وعادات وسجل تاريخي.
- مراجعات يومية وأسبوعية وتعافٍ ولوحة قيادة محسوبة من بيانات المستخدم.
- ملاحظات Markdown وبحث وروابط داخلية وخلفية.
- جلسات تركيز ووضع صارم لحجب التطبيقات، ومرشح DNS للمواقع.
- حسابات وأصدقاء وتحديات وترتيب ومشاركة بصلاحيات ومزامنة اجتماعية آمنة من التكرار.
- نسخ احتياطية مشفرة مع المرفقات واستعادة ذرية، وحفظ رمز الحساب في Android Keystore.

القائمة الدقيقة وحدود كل ميزة في [STAGE3_ACCEPTANCE.md](STAGE3_ACCEPTANCE.md). نتائج التحقق في [VERIFICATION.md](VERIFICATION.md)، والتحقق الإضافي من Android في [ANDROID_TEST_RESULTS.md](ANDROID_TEST_RESULTS.md). ملفات المتابعة القديمة محفوظة كسجل تاريخي فقط.

## بناء Android

يتطلب JDK 17 وAndroid SDK Platform 37 وBuild Tools 36.0.0. ضع مسار SDK في `local.properties` على جهازك، أو استخدم Android Studio.

```bash
./gradlew clean --no-build-cache :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

ينزل سكربت `gradlew` إصدار Gradle المحدد عند أول تشغيل. يتطلب البناء الأول اتصالاً بمستودعات Google وMaven. يعمل التطبيق بدءاً من Android 8 (API 26).

## التعاون

اقرأ [server/README.md](server/README.md) لتشغيل الخادم والاتصال من الهاتف أو المحاكي. الخادم غير منشور على الإنترنت ضمن هذه الحزمة. قاعدة الحياة لا ترفع تلقائياً: المشاركة والمزامنة الاجتماعية صريحتان، ونقل البيانات الشخصية بين الأجهزة عبر النسخة المشفرة.
